 AldoraCart

An e-commerce front-end web app built with Angular and Signals for state management.

🔗 Live demo: https://ecommerce-six-drab-n254t1l4z6.vercel.app

About

AldoraCart is a front-end practice project focused on building a responsive shopping experience with modern Angular.

Note: This project has no custom backend. All data comes from a public third-party API on the internet, so the focus here is entirely on the front-end.

ng serve
